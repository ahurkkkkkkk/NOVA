# NOVA

NOVA is a Persian-language Telegram assistant with a web workspace for subscriptions and channel operations

## What it includes

- A storefront where customers can compare plans and manage their account
- Shared plan settings so admins can update prices, durations and features from the web panel or Telegram bot
- Channel workflows for publishing, feed management and duplicate screening
- Telegram Stars checkout for Telegram digital services

## Project status

NOVA is developed in stages and some moderation and approval workflows still need work
Crypto checkout still needs a payment provider and backend integration
This overview does not claim that every feature is production ready

## Repository contents

This public repository intentionally contains only this README
It does not contain bot or web app source code, credentials, customer data, binaries or design assets
